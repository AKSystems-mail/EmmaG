# Emma G Adventures

A 1st-grade educational app — reading, math, science, and world lessons delivered as illustrated storybook carousels with quizzes, badges, and bonus challenges. Built for my daughter's birthday party as a gift for her and her friends.

**Stack:** Flutter (Dart) + Firebase (Auth, Firestore, Cloud Functions) + Google AI (Gemini 2.5 Pro + Imagen 4 Fast).

## What it does

- Anonymously signs in each child and tracks per-child progress in Firestore.
- Each subject is a set of topics, each topic is 10 levels.
- A level is a **storybook carousel**: a generated background image, ~3 short sentences (each ≤9 words), a visual-vocabulary keyword per slide, and a multiple-choice quiz.
- Badges and bonus challenges reward completion.
- Text-to-speech reads lessons aloud (a 1st grader can't read everything).

## The interesting part: content is generated, not written

Every lesson is produced by an AI pipeline, not hand-authored. `generate_content.py` takes an image, sends it to **Gemini 2.5 Pro** (vision), and gets back a full lesson JSON — introduction, slides, keywords, quiz — then generates the illustration with **Imagen 4 Fast**. The 10-topic reading curriculum is defined in that same file; ~9,700 files of generated lessons and images are the output.

The generation scripts (`generate_content.py`, `generate_bonus_challenges.py`) and upload scripts (`upload_bulk.py`, `upload_to_firestore.py`, `upload_bonus_challenges.py`, `clean_existing_quizzes.py`, `create_badge_docs.py`) live at the repo root. They were written as throwaway one-offs for this app, but the pipeline itself — "turn a folder of images into an illustrated kid's lesson pack" — is the reusable core. See [Ideas for this repo](#ideas-for-this-repo).

## Project structure

```
lib/                   Flutter app (main, subject/quiz/badge screens, TTS)
functions/             Cloud Functions (src/)
generate_content.py    Lesson + image pipeline (Gemini 2.5 Pro + Imagen 4 Fast)
upload_*.py            Firestore seed/upload scripts
clean_existing_quizzes.py, create_badge_docs.py   maintenance scripts
generated_content/     JSON lessons (gitignored — regenerated)
assets/generated_images/  lesson illustrations (gitignored — regenerated)
```

## Running it

**Prereqs:** Flutter 3.x, a Firebase project, a Google AI API key.

```bash
flutter pub get
flutter run
```

The app expects Firebase config in `lib/firebase_options.dart` (generated by `flutterfire configure`). It uses anonymous auth, so no account setup is needed for kids.

### Regenerating content

The lesson JSON and images are **not** committed — they're build output. To regenerate:

```bash
# 1. Create a venv and install deps
python3 -m venv .venv && source .venv/bin/activate
pip install google-genai vertexai firebase-admin

# 2. Set your API key and run the pipeline
export GEMINI_API_KEY=...
python3 generate_content.py
```

The scripts read `API_KEY` from the top of each file — they predate env-var config, so you'll want to swap the placeholder for your key (or better, read from `os.environ`, which is a nice first PR).

## Security note

This repo originally committed a live Firebase service-account key and hardcoded Gemini keys. Those were revoked and scrubbed from history before this repo went public. The Firebase client keys in `lib/firebase_options.dart` / `google-services.json` are **public by design** (they ship in every app bundle); server-side secrets live in env/config and are gitignored.

## Ideas for this repo

- **Extract the pipeline into a standalone CLI** — `genlessons ./photos --grade 1` → lessons. Framework-agnostic, no Flutter. This is the most reusable artifact here.
- **Parent/teacher "make a lesson" mode** — expose the pipeline behind a button.
- **Read API key from env var** instead of hardcoding it in the scripts.
