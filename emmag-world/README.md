# Emma Grace's World (web game)

Standalone three.js/Vite game, deployed to https://emmaga2.web.app (Firebase project `emmaga2`).
Kept in this subfolder as a backup; it is not part of the Flutter app at the repo root.

```sh
npm install
npm run dev      # local
npm test         # math self-check
npm run build && firebase deploy --only hosting
```
