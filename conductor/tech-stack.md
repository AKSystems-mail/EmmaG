# Tech Stack

## Frontend
- **Framework:** Flutter
- **Platform:** Web, Android, iOS

## Backend
- **Database:** Firebase Firestore
- **Storage:** Firebase Storage (for images)
- **Functions:** Firebase Functions (Node.js/TypeScript)

## Content Generation
- **LLM:** Gemini 2.0 Flash-Lite (via `google-genai` SDK)
- **Image Gen:** Imagen 4 Fast (via Vertex AI)
- **Scripting:** Python 3.9
